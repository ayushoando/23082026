Skills and external capability

Say “Use the repository skills” or name `repo-map`, `graph-impact`, `focss-css`, `fork-boundaries`, `planner-studio`, `db-migrations`, or `verify-and-gate`; `oando-master` routes all repository tasks.

MCP is not required for normal source/UI/migration/test/script/docs work. Consider it only for a recurring approved live-provider/external-system need, starting read-only and least privilege.
