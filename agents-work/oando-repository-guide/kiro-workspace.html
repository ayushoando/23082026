Choose the least powerful extension

  1. Use repository code/docs/native Kiro tools for one-off local work.
  2. Use steering/skills for recurring knowledge or procedure.
  3. Use a power when a recurring workflow needs bundled knowledge/tools.
  4. Use an MCP only for reviewed, recurring live external data/actions unavailable through the above.
Assess whether a skill, steering rule, power, or MCP fits [need]. Prefer the least
powerful option. If external integration is justified, propose read-only,
least-privilege setup and fallback; do not configure it yet.
