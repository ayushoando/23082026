Command permission

Checks, builds, browser tests, DB actions, deploys, backups, and other test-like operations require your explicit current-session authorization. Grant only the commands you intend.

You may run only `pnpm run typecheck` from the repository root and report the result.
You may run `pnpm run scan:boundaries` and `pnpm run p0:unit` for this Planner change.
Do not run any other command.
For data/release work, demand target environment, exact command, risk, backup, and rollback before authorizing execution.
