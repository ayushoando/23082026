What this guide covers

This is no longer a product-only or MCP-only guide. It maps all meaningful repository areas: application source, APIs, databases, tests, scripts, configuration, CI, operations, documentation, planning, Kiro workspace controls, environment files, generated output, editor/tool state, and root control files.

Scope boundary: “Every area” means every maintained functional area and status category. It intentionally does not list every dependency file, build cache entry, or individual generated artifact.

Five facts that prevent mistakes

  1. Marketing (`/`), Admin (`/admin/*`), Studio (`/oostudio`), and Planner (`/ooplanner`) are distinct surfaces.
  2. Planner and Studio are forked and never import each other.
  3. Products DB owns marketing/configurator; Admin DB owns staff/customer/plans/furniture/descriptors.
  4. Production filesystem is read-only; route writes use mode-aware persistence wrappers.
  5. Use root `pnpm`; there is no product `site/package.json`.

Live-tree corrections

There is no root supabase/ directory: use site/platform/supabase/. There is no root mcp/ directory: use .kiro/mcp/. The guide follows the live tree rather than stale generic paths.
