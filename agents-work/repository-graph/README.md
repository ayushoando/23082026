# Repository graph reports

All graph reports are kept under this folder. Graph tooling reads repository source but must not write under `site/`.

## Layout

- `page-components/` — route/page/component/module/style graph artifacts.
- `stats/latest.json` — whole-graph file, edge, domain, fan-in, and fan-out statistics.
- `cycles/latest.json` — strongly connected local-import components.
- `impact/<domain>/` — per-file transitive-dependent reports.

The JSON reports are generated by repository scripts. Do not hand-edit them; rerun
the relevant command from the repository root.
