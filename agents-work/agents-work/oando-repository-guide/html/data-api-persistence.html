Security, i18n, public contract

Security

site/proxy.ts, server auth helpers, CSRF, rate limits, RLS, server-only secrets.

i18n

site/i18n/ holds messages/config; root i18n/request.ts is the resolver shim; runtime currently loads English.

Public assets/discovery

site/public/, robots/sitemap/security/discovery routes and metadata.

Safe migration prompt

Use the database-migration workflow for [change]. Decide Products versus Admin.
Draft grants, RLS, and -- rollback. Identify types, API contracts, application code,
tests, and the dry-run. Do not apply it.
