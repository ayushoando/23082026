Important boundaries

  • All report and guide work stays under agents-work/.
  • The hub depends on the existing child reports; do not delete or rename them without updating this file.
  • Planner and Studio are forked and must not import each other.
  • Products owns marketing catalog/configurator data; Admin owns staff, customer, plans, furniture, and descriptors.
  • Static reports do not prove browser behavior, hosted persistence, deployment, or connected MCP state.
