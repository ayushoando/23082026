07 · Dependency intelligence

Measure blast radius before guessing.

The import graph replaces a manual search through dependents. It tells you where a change travels and which tests are worth running.

11 · Completion

Done means evidenced.

Before you say the work is complete, re-read the original request, check the exact files and behavior, and report what you actually verified.

  • User criteria re-read
  • Correct source and boundaries
  • Impact and focused tests checked
  • Relevant gate passed
  • No secrets or unrelated edits
  • Blockers reported honestly
