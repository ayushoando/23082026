# Tasks: Page-wise FOCSS CSS remediation

This is the implementation task plan for the 61-route audit. It does not implement the changes. Work must follow the existing FOCSS zone and the verified owners in each row.

## Legend

- `T` = text sample below 11px.
- `H` = interactive target below 40px.
- `F` = missing `contentinfo` heuristic; classify the shell before editing.
- `N` = visible control group without an accessible name; markup task.
- `E` = console-error finding; runtime task.
- `OK` = no finding in that viewport for the listed category.
- `CSS` = presentation work at a verified CSS owner.
- `M` = markup/accessibility work.
- `R` = runtime investigation/fix.
- `AC` = audit-contract or redirect disposition.
- `OG` = owner gap; no live component/CSS owner was verified.

The five viewport columns are always `1920`, `1440`, `1078`, `768`, and `390`. The source audit is `results/site/page-audit-production-complete/audit-results.json`; route/source/dynamic evidence is `results/site/page-audit-production-complete/route-inventory.json`.
