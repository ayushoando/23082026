## Executive Summary

The `generated-documents/` directory is the compiled output of the Tech-Docs Generator extraction pipeline. It is correctly gitignored and ephemeral. The **critical finding** is the actual total size: **124 MB across 80 files**, dominated by `repo-graph.json` (32.38 MB). The prior report's "~35 MB" total was wrong — the full directory is 3.5× larger than stated.

## 2. Key Findings & Health Assessment

### Finding 1: `repo-graph.json` Size Risk (32.38 MB) ✅

Loading this unminified 32 MB JSON into a browser SPA causes V8 heap pressure or main-thread freeze. The Tech-Docs SPA must **not** load this file directly. If the `/repository-graph` route is ever wired into `App.tsx` (see tech-docs App.tsx audit), it must use chunked loading, Web Workers, or a pre-filtered subset.

### Finding 2: Graph Orphan — `page-component-graph.mmd` Never Rendered ✅

`generated-documents/repository-graph/page-components/page-component-graph.mmd` is generated by `generate-page-component-graph.mjs` but `tech-docs-generator/src/App.tsx` has **no `/repository-graph` route**. The output is computed and written to disk, then never displayed. This is confirmed in the operational audit.

### Finding 3: Total Size Is 124 MB, Not ~35 MB ⚠️ NEW

The prior report implied ~35 MB. Live measurement: **80 files, 124 MB total**. Cause is likely the `docs/` directory containing `_sources.json` (5.3 MB per prior report) plus other staged content, plus possible duplicate root-level files.

### Finding 4: Gitignore Coverage ✅

`generated-documents/` is correctly in `.gitignore`. No 34 MB blobs committed to Git.

### Finding 5: `filesystem.mjs` Wipe-Before-Generate ✅ (Claimed, Not Re-Verified)

Prior report states `cleanGeneratedRoot()` wipes `generated-documents/` at pipeline start. This is a sound practice and consistent with the directory being ephemeral.
